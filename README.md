# Solar Fin 幕墙数字孪生 Demo

CWISA 2026 概念演示。保留中环开放数据场景，新增 R02 顶部铰接外屏、四种方案的同条件对照、简化角度搜索和实验角度记录回放。

## 运行与检查

需要 Node.js 22 或更新版本运行测试和打包。网页本身无需安装依赖。

```sh
npm test
npm run build
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

在浏览器打开 http://127.0.0.1:8765/ 。也可在仓库根目录直接运行静态服务器。

GitHub Pages 地址：https://the-unknown-01.github.io/curtainwall-glare-preview/

## 演示流程

1. 在场景总览选择建筑、日期和香港时间，拖动外屏角度。
2. 切换原幕墙、收拢、固定30度和可动外屏；在方案对比中查看同一场景结果。
3. 点击搜索，获得0–50度范围内的当前时刻候选角度；这不是安全运行许可。
4. 实验回放内可播放合成示例，或导入自己的JSON/CSV角度记录。
5. 导出记录获得配置、模型假设、完整光路、对照结果和回放来源。

## 模型边界

- 城市采用固定计算采样，设备差异仅影响绘制细节。计算几何使用 ENU 米制坐标。
- R02外屏按顶部铰接运动，原幕墙固定；包括外屏反射和透射到原玻璃再反射的简化分支。
- 窗间距、模块尺寸和材料为演示假设，覆盖整面候选立面；没有局部面板选择或全年风险图。
- 方向占比是源端简化反射权重的几何代理，不是照度、眩光概率、受害人数或实测改善率。
- 第二跳邻楼暂按镜面处理；有限边缘、折射位移、复杂散射和后续互反射未建模。出域路径仍是未评估。
- R02丝杠行程图按a=240、e=60、l=300mm示例计算；不能作为城市实装尺寸或采购依据。
- 收拢仍保留额外玻璃，覆盖区相对透光估算为假设的T=0.65，不代表实测采光。
- 默认记录为明确标注的合成数据；本应用不连接、不控制硬件，也不宣称消防、结构或抗风认证。

## 导入记录

最多2MB、2–2000条。时间必须严格递增且包含Z或时区偏移；angle_deg为0–50度，可选target_deg同范围。仅在浏览器本地处理，文件不会上传。

```csv
timestamp,angle_deg,target_deg
2026-10-25T15:00:00+08:00,0,0
2026-10-25T15:00:01+08:00,3,30
2026-10-25T15:00:02+08:00,6,30
```

也支持相同字段的JSON数组，或对象的records数组。回放只映射角度，城市太阳日期／时刻保持独立。导入只验证格式，不验证仪器校准或数据真实性。未接入的锁扣与设备状态保持未知。

## 发布

`.github/workflows/pages.yml` 在main更新时执行三组测试、打包dist并部署GitHub Pages；站点发布源配置为GitHub Actions。静态包仅包含网页所需文件，不包含Git元数据、测试和历史仿真文件。
